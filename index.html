📖 Tokio API Reference & Cancellation Safety

Searchable directory of Tokio primitives and cancel-safety properties in select! branches.

API / Primitive Module Cancel Safe? Summary & Production Usage
tokio::select! tokio Safe Races multiple futures concurrently; resolves the winner and immediately drops the losers.
TcpListener::accept() tokio::net Safe Awaits the next connection. If dropped before ready, socket remains undisturbed in kernel listen backlog.
AsyncReadExt::read() tokio::io Safe Reads incoming bytes. If cancelled before completion, no bytes were yet transferred out of the buffer.
AsyncWriteExt::write_all() tokio::io UNSAFE Transfers entire buffer. If dropped mid-way, partial bytes may already be written, leaving connection corrupt.
mpsc::Receiver::recv() tokio::sync Safe Awaits next channel item. If dropped before message arrives, message remains queued for subsequent recv.
tokio::time::sleep() tokio::time Safe Async timer. Dropping Sleep cancels timer entry in runtime timing wheel without side-effects.
tokio::spawn() tokio::task Safe Spawns standalone async task onto Tokio worker threadpool. Yields JoinHandle with .abort() capability.
tokio::task::spawn_blocking() tokio::task Conditional Offloads synchronous heavy CPU or blocking I/O onto a dedicated blocking threadpool. Prevents reactor stalls.
